# Amr Mahmoud — Portfolio

A one-page portfolio for Amr Mahmoud, a React.js developer in Assiut, Egypt. The page uses the Bellatrix UI tokens: a navy hero, light cards, one blue action color, and a dark-mode option.

## What is public

Featured work is limited to repositories that can be opened:

- [Admin dashboard](https://github.com/a-mfarghly/dashboard-task) — [live demo](https://dashboard-task-pi.vercel.app)
- [Fresh Cart](https://github.com/a-mfarghly/e-commerce3) — [live demo](https://e-commerce3-taupe.vercel.app)
- [Commerce API](https://github.com/a-mfarghly/Ecommerce-site-Backend-main)
- [Pharmacy app](https://github.com/a-mfarghly/pharmacy-management-may-12)

The contact form opens the visitor's email app. It does not send mail by itself. Two CVs are available for download: `assets/amr-mahmoud-frontend-cv.pdf` and `assets/amr-mahmoud-odoo-cv.pdf`. LinkedIn is [amr-mahmoud-885053279](https://www.linkedin.com/in/amr-mahmoud-885053279/).

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8765
```
